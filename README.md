# Data Structures and Algorithms in C++

This repository contains a comprehensive collection of C++ programs covering fundamental programming concepts, Data Structures, and Algorithms.

## 📁 Repository Structure

The project is divided into two main sections:
- **C++**: Fundamental concepts (Basics, Loops, Functions, Pointers, Arrays, Vectors).
- **DSA**: Advanced topics (Linked Lists, OOPs, Stacks, Queues, Recursion, Searching, Sorting).

---

## 🛠️ C++ Fundamentals

### 1. Basics (`C++/basics/`)
- `firstprogram.cpp`: Introduction to C++ syntax.
- `02_basic.cpp` & `03_varaiables.cpp`: Understanding variables and basic I/O.
- `04_increment.cpp` & `05_increment2.cpp`: Post and pre-increment operators.
- `areaofcircle.cpp`: Calculation using mathematical formulas.
- `bool.cpp` & `chardatatype.cpp`: Working with different primitive data types.
- `typeconversion.cpp`: Implicit and explicit type casting.
- `printfractionalpart.cpp`: Extracting fractional parts from floating-point numbers.

### 2. Control Flow (`C++/if_if/`)
- `if_elseif.cpp` & `if_else_ladder.cpp`: Conditional logic.
- `switchcase.cpp`: Multi-way branching.
- `ternary.cpp`: Using the conditional operator for concise logic.

### 3. Loops (`C++/LOOPS/`)
- `01_basics.cpp`: Introduction to `for`, `while`, and `do-while` loops.

### 4. Functions (`C++/functions/`)
- `01_basics.cpp`: Defining and calling functions.
- `03_pascals_traingle.cpp`: Generating Pascal's Triangle using functions.
- `06_gcd.cpp` & `07_gcd2.cpp`: Finding the Greatest Common Divisor.
- `05_default_vaules_argu.cpp`: Working with default function arguments.

### 5. Pointers (`C++/pointers/`)
- `01_basics.cpp` to `05_pointer_syntax.cpp`: Pointer declaration, initialization, and dereferencing.
- `03_pass_by_reference.cpp`: Modifying variables using pointers in functions.
- `07_pointer_arithmetic.cpp`: Navigating memory using pointers.
- `10_double_pointers.cpp`: Understanding pointers to pointers.

### 6. Arrays & Vectors (`C++/ARRAYS/`)
- **Arrays**:
  - `01_array.cpp`: Basic array operations.
  - `02_second_max.cpp`: Finding the second largest element in an array.
  - `03_linear_search.cpp`: Searching for elements in an array.
- **Vectors (`LEC - 02/Vectors/`)**:
  - `01_vector_basics.cpp`: Introduction to dynamic arrays (Vectors).
  - `05_vector_At_Sort.cpp`: Using `.at()` and `sort()` functions.
  - `10_two_sum.cpp`: Solving the Two Sum problem.
  - `14_rotate_by_k.cpp`: Rotating a vector by $k$ positions.
  - `15_sort_01.cpp`: Sorting an array of 0s and 1s efficiently.

## 🚀 Data Structures & Algorithms (DSA)

### 1. Object-Oriented Programming (`DSA/OOPs/`)
- `01_Basics.cpp`: Class and Object creation.
- `02_DMA.cpp`: Dynamic Memory Allocation for objects.
- `03_Nested_Class.cpp`: Classes within classes.
- `01_CONSTRUCTOR.cpp` to `04_COPY_Constructor.cpp`: Deep dive into Constructors and Destructors.

### 2. Linked List (`DSA/LINKED LIST/`)
- `02_Node_Class.cpp`: Defining a node structure.
- `04_LINKED_LIST.cpp`: Manual implementation of a linked list.
- `05_LINKED_LIST_TRAVERSAL.cpp`: Iterating through nodes.
- `08_DISPLAY_RECURSIVELY.cpp`: Printing a linked list using recursion.
- `10_LL_SIZE.cpp`: Calculating the length of a linked list.

### 3. Stack (`DSA/STACK - STL/`)
- `01_BasicSTL.cpp`: Using `std::stack` from the STL.
- `02_reverse_STACK.cpp`: Reversing elements using an auxiliary stack.
- `03_Push_at_bottom.cpp`: Inserting an element at the bottom of a stack.
- `ARRAY_IMPLEMENTATION/`: Custom stack implementation using arrays and vectors.
- `STACKS-2/`: Problems like Balanced Brackets and Next Greater Element.
- `STACK-3/`: Infix expression evaluation.

### 4. Queue (`DSA/QUEUE/`)
- `01_BASIC.cpp`: Basic queue operations (enqueue, dequeue).
- `05_ARRAY_IMPLEMENTATION.cpp`: Custom queue using arrays.
- `06_LL_IMPLEMENTATION.cpp`: Queue using a Linked List.
- `07_DLL_DEQUE.cpp`: Double Ended Queue (Deque) implementation.
- `QUEUE-2/`: Problems like "First negative in every window of size k".

### 5. Recursion (`DSA/RECURSION/`)
- `05_factorial_recursion.cpp`: Classic factorial problem.
- `07_print_1_to_n_after_call.cpp`: Understanding head vs tail recursion.
- `11_a_raised_to_b.cpp`: Power function implementation.
- `02_fib_rec.cpp`: Fibonacci sequence using recursion.

### 6. Searching Algorithms (`DSA/SEARCHING/`)
- `01_Linear_Search.cpp`: Sequential search.
- `02_Binary_Search.cpp`: Efficient search in sorted arrays.
- `04_lower_bound_binary.cpp` & `05_Upper_bound_binary.cpp`: Finding bounds using binary search.
- `08_find_smallest_missing_binary.cpp`: Application of binary search.

### 7. Sorting Algorithms (`DSA/SORTING/`)
- `BUBBLE_SORT/`: Traditional and optimized bubble sort implementations.
- `SELECTION_SORT/`: Selection and Insertion sort.
- `QUICK SORT/`: Quick sort implementation using partitioning.

## 💻 How to Run
1. Ensure you have a C++ compiler installed (like `g++`).
2. Navigate to the directory containing the file.
3. Compile using:
   ```bash
   g++ filename.cpp -o output
   ```
4. Run the executable:
   ```bash
   ./output
   ```
